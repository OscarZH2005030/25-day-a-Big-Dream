## 二、基线方法

### Task 1：星期 × 日内时刻历史均值

对每个检测 link，按星期几和 5 分钟时段统计历史平均速度与流量。缺少该时段画像时，回退到该 link 的整体训练均值。时间留出评估严格使用 2031-02-01 之前的数据拟合，避免把留出月的信息泄漏到预测中。官方 validation/private 预测则用全部可用训练期拟合后，按官方模板的行序写出。

### Task 2：队列状态 persistence

使用官方 persistence 基线：从窗口历史末端读取最近状态，以 `0.6 × free-flow speed` 规则判断队列，并将该状态延续到未来 6 个 5 分钟时刻（+5 至 +30 分钟）。训练集没有随包发布可直接用于评分的官方队列真值，因此本地诊断标签由完整训练速度按规则推导，只能作为代理评估。

## 三、重新运行结果

### Task 1 时间留出

- 总分 `S_state = 0.730602`，评估 **3,443,944** 条目标记录。
- 走廊族得分：D12_I405 `0.813028`；D12_I5 `0.646582`；D7_I10 `0.765741`；D7_I210 `0.843911`；D7_I405 `0.583749`。
- 分数按五个 corridor family 等权汇总；每个 family 内先合并方向，再对 R1/R2/R3 regimes 做等权组合。
- R1/R2/R3 的 `S_state` 分别为 `0.7471 / 0.7280 / 0.7166`。速度子分低于流量子分，说明该简单画像对速度变化尤其是异常拥堵时段的跟踪能力有限。

### Task 2 训练代理评估

- 80 个窗口的平均 IoU 为 **0.307378**（40 个 queue-onset、40 个 queue-ongoing）。
- ongoing 平均 IoU **0.589756**；onset 平均 IoU **0.025000**。
- 这反映 persistence 对已经形成并持续的队列有一定延续能力，但几乎不能提前识别新队列形成。onset 的小幅非零值可能来自速度测量噪声与阈值附近波动。
- 上游仓库报告的 validation persistence 参考分为 **0.3017**，它与这里由训练速度推导出的代理分数不是同一评估集/真值来源，不能直接比较。

## 四、结果说明了什么、当前问题是什么

- Task 1 的历史均值可以作为可运行、可复现的参考线，但它不利用同一天已观测到的上下游状态，也没有显式表示拥堵传播、时空相关性和交通守恒。
- 当前 Task 1 的弱项集中在 D7_I405 与 D12_I5，速度预测尤其弱；这些走廊/状态可优先排查数据分布差异、自由流与拥堵混合以及 regime 覆盖。
- Task 2 persistence 在 queue-onset 场景基本失效。后续改进重点应转向队列出现概率、上游传播特征及 onset/ongoing 分开建模。
- Task 2 代理真值来自有噪声的测量速度，并非隐藏模拟器状态生成的官方队列标签，因此 `0.307378` 不应写成 Kaggle validation/private 分数。
- 两项预测文件是 per-task 输出，不是最终提交 CSV。集成负责人仍需按官方 `submission_key.csv` 与提交模板把四项任务结果合并。
- 团队计划由 A 负责 Task 1+3，B 负责 Task 2，C 负责 Task 4 与工程整合；截图没有说明 A/C 对应的姓名。团队已确认 Task 1 全员共同负责，Oscar 是 B，负责 Task 2。

```powershell

python scripts/build_task1_historical_mean.py --split both
python vendor/trafficflowbench-public/src/task2/build_task2_persistence_submission.py --release-root data/kaggle_public --split train --output outputs/task2_persistence_train.csv
python vendor/trafficflowbench-public/src/task2/build_task2_persistence_submission.py --release-root data/kaggle_public --split validation --output outputs/task2_persistence_validation.csv
python vendor/trafficflowbench-public/src/task2/build_task2_persistence_submission.py --release-root data/kaggle_public --split private --output outputs/task2_persistence_private.csv
python scripts/evaluate_task2_train_proxy.py
python scripts/validate_oscar_baselines.py
```

全部脚本及预测均已在本次复跑中成功运行；最后的校验输出显示所有预期行数、键和值域检查通过。
