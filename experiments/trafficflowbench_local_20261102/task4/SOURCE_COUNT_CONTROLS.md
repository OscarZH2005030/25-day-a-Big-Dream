# 来源计数校正没有解决这组人工配对风险

已有压力结果显示，跨输入组弱先验的可预测性可能与真实OD收益分离。新的固定种子2026110321检验一个具体补救配方：先用来源组自己的观测计数和先验做非负lambda0.05求解，再从来源估计中提取配对特征。

480例包含四种需求形状、四种独立／共享误差、三种需求变化机制和十个公开网络。原始来源与校正来源共享同一目标五折、同一生成案例和固定混合强度。学习器仅接收几何、提供的先验、生成的可观测计数和折分；来源真实路径不作为特征。

## 相同案例、相同强度的结果

全部2880个最终动作可用，来源求解也均成功。平均人工分为正不能掩盖退步数增加。只在这480例内配对比较，不把它与旧960例合并为一套独立验证集。

这否定的是这一具体配方的稳健性收益，不是证明所有来源计数方法都无用。校正后的非负估计会产生零值，其归一化及截断会改变源特征尺度；其他尺度控制需要新登记的对照。

给定完整起终点边际后，本发布计数不再提供额外配对方程（见[独立整数恒等式](OD_PAIR_INFORMATION.md)）。因此，来源计数校正可以影响边际和先验推断，却没有提供一个可直接验证纯匹配正确性的观测标签。
