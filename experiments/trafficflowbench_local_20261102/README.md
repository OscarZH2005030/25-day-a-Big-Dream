## Task4：重点是恢复 OD 配对，而非继续逼近 S_link=1

官方：`S_ODME=.45*S_od+.25*S_link+.15*S_dev+.15*S_attr`。S_dev比较偏离弱先验的幅度与真实幅度，不是越贴近先验越好。

实际发布网络审计得到：

1. 十个方向都为一个OD对对应一条发布路径，主要是在恢复OD矩阵。D12_I405_N有903个OD对，计数矩阵秩42；全部起终点边际已知仍有820个线性不可识别方向。
2. 在30个方向/切分上，严格满足公开计数和非负性的总需求最大/最小比值达18.68—30.89。D12_I405_N validation为25.40倍，两端计数NMAE不超过浮点误差。这是可行性范围，不是合理需求估计。弱先验会排除一部分极端解。
3. 更严格的160个真实网络反例，同时保留基准计数、全部起终点边际、先验L1偏离量。S_link/S_dev/S_attr因此保持相同，但OD向量相对基准的L1差异仍为0.2368—0.6406。它们既不是更好模型，也没有隐藏分数；说明S_od的45%承担核心区分作用。
4. 公开主线UTC15—19均值与Task4聚合计数平均仍有约3.6%—3.9%的NMAE，原始匝道ID也未直接匹配Task4计数。不能未经时间/生成/拓扑核验就把它们加入硬约束。

### 推断方法试验：守恒后验采样通过混合诊断，尚未验证真实OD

为区别“拟合道路计数”和“恢复OD不确定性”，试验在 `f>=0, A*f=c` 的可行域上采样Gaussian模型 `exp(-||f-b||²/(2σ²))`。长OD与两段短OD的三角恒等式给出严格守恒的局部方向，沿方向用截断正态条件分布更新。**Gaussian先验误差假设并未由真实路径标签证明**，计数协方差证据也不能识别全部零空间分布。

- 一维闭式对照：12,000次条件抽样，KS统计量0.00633；实际道路全部12,341个三角方向验证守恒。
- 初始三种尺度的短链均失败，最大raw split-Rhat约1.307/1.284/1.072，负结果保留，没有据此排名。
- 只延长预先默认的中央尺度：四链、1000个预热sweep、2000个保存sweep；全部903路径的最大raw split-Rhat **1.01957**、最小粗略ESS **164.99**，总量/先验距离/logdensity也通过原定门槛。
- 独立回读全部8,000个样本，最大计数误差2.28e-11，样本非负；单独向量化重算全部路径Rhat，与原计算最大差2.23e-16。
- 无旧工作区的可移植长链复跑诊断差0，原始模型抽样数组SHA256也一致。

**这仅说明此单路假设模型的数值推断达标，不是真实OD分数或新官方候选。** 尚未对真实输入做后验“自评分”排名，也未替换基准。下一步以已知人工潜在需求的小网络检查匹配模型和错误噪声/稀疏反例；只有通过收敛检查的案例才参与配对比较，失败率同时保留。


[同案例、同强度的来源对照及局限](task4/SOURCE_COUNT_CONTROLS.md)：来源组先用自身计数校正的具体配方未减少人工退步；5%强度的综合退步由57/480增至106/480。全部2880个动作和产物哈希经独立完整复算一致，不据此泛称计数无用。后续OD交换算法的数值检查已通过，研究性实际效果仍在测试，未替换官方方案。
